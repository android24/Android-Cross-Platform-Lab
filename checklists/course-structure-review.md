# 课程结构执行审验

本清单用于检查课程是否按照既定路线执行。

## 四层结构

| 层级 | 作用 | 审验问题 |
| --- | --- | --- |
| 课程路线 | 原理课到实验课的总路径 | 是否承接 Cross-Platform Internals |
| 课程结构 | 七篇内容的正式目录 | 是否严格按七篇展开 |
| 章节目录 | 每篇下的教学主题 | 是否与该篇规划一致 |
| 实验任务 | 贯穿项目的动手任务 | 是否服务正文而不是替代正文 |

## 篇章映射

| 篇章 | 对应章节 | 工程目录 |
| --- | --- | --- |
| 第一篇：Android 原生基准 | 第3章 | `native-android/` |
| 第二篇：Web、PWA 与 Hybrid | 后续章节 | `web-pwa/`、`hybrid-webview/` |
| 第三篇：React Native | 后续章节 | `react-native/` |
| 第四篇：Flutter | 后续章节 | `flutter/` |
| 第五篇：Kotlin Multiplatform | 后续章节 | `kmp/`、`compose-multiplatform/` |
| 第六篇：特色跨平台专题 | 后续章节 | `unity-android-demo/` 等 |
| 第七篇：性能、架构与选型 | 后续章节 | `benchmarks/` |

## 审验项

| 项目 | 审验问题 | 状态 |
| --- | --- | --- |
| 路线一致性 | 章节是否服务“原理到工程”的学习路径 | 本次通过 |
| 篇章一致性 | 章节标题是否对应七篇结构 | 本次通过 |
| 主题一致性 | 小节是否严格覆盖该篇规划主题 | 本次通过 |
| 项目一致性 | 每章是否落到智能座舱贯穿项目 | 本次通过 |
| 工程一致性 | 每章是否对应明确工程目录 | 本次通过 |
| 对照一致性 | 是否说明与后续技术栈的比较关系 | 本次通过 |
| 审验隔离 | 正文是否避免把验收标准作为主线 | 本次通过 |

## 处理规则

如果某一章偏离篇章规划，优先调整章节结构；如果某一节内容像任务卡或验收表，优先迁入实验路线图或审验清单。
