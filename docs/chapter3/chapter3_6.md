本节实现原生基准中的本地缓存能力。缓存不仅用于提升体验，也用于后续和 PWA、Hybrid 离线包、RN/Flutter 本地存储、KMP 数据库方案进行比较。

## 缓存范围

| 能力 | 阶段 | 说明 |
| --- | --- | --- |
| 收藏 | 核心/增强 | 保存用户收藏条目 |
| 浏览历史 | 增强 | 保存最近浏览文章 |
| 搜索历史 | 增强 | 保存最近搜索词 |
| 手册数据缓存 | 增强 | 支持离线浏览已缓存内容 |
| 图片缓存 | 增强 | 支持离线展示已缓存图片 |
| 设置缓存 | 增强 | 主题、语言、离线模式 |

## 存储选择

| 数据类型 | 可选方案 |
| --- | --- |
| 简单设置 | DataStore |
| 收藏、历史、搜索词 | Room 或 DataStore |
| 手册数据缓存 | Room、文件缓存或预置 assets |
| 图片缓存 | 图片库缓存或自定义文件缓存 |

课程中不强制唯一方案，但要记录选择理由，因为后续跨平台技术栈的本地存储能力差异很大。

## 离线模式

离线模式至少要明确：

- 离线开关状态是否可见。
- 离线时是否仍能浏览已缓存内容。
- 未缓存内容如何提示。
- 图片加载失败是否会导致白屏。

## 实验任务

1. 实现收藏和取消收藏的持久化。
2. 实现浏览历史或搜索历史。
3. 为手册数据或图片预留缓存策略。
4. 增加离线模式开关。
5. 记录当前缓存方案和限制。

## 完成后复盘

- 应用重启后收藏或历史仍存在。
- 删除或取消收藏后 UI 及时刷新。
- 离线模式下核心浏览流程不依赖真实网络。
- 未缓存内容有明确提示。
