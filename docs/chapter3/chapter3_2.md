本节实现原生基准工程的页面导航。导航结构会成为后续 Hybrid、React Native、Flutter 和混合接入方案的对照点。

## 本节产物

完成本节后，应用应该从“一个首页”扩展为“可切换的原生基准应用”：

- 首页/目录页能展示目录和详情。
- 搜索、车辆状态、原生能力、设置等页面有明确入口。
- 横屏优先使用主从布局，小屏可以切换为单页导航。
- 当前页面和当前选中文章不会因为普通重组而丢失。

## 页面清单

| 页面 | 阶段 | 说明 |
| --- | --- | --- |
| 首页/目录页 | 核心 | 左侧目录，右侧详情 |
| 手册详情页 | 核心 | 图文说明、收藏入口、历史记录 |
| 搜索页 | 核心 | 全局搜索和搜索结果 |
| 车辆状态页 | 核心 | 模拟车辆数据展示 |
| 原生能力页 | 核心 | 文件、相机、通知入口 |
| 设置页 | 增强 | 主题、语言、离线模式 |
| 收藏页 | 增强 | 收藏条目列表 |
| 历史页 | 增强 | 浏览历史列表 |
| 性能测试页 | 毕业增强 | 启动、列表、图片、数据刷新入口 |

## 导航原则

- 横屏车机场景优先使用主从布局。
- 小屏可以退化为单列、抽屉或底部导航。
- 页面路由不应和具体数据读取逻辑强绑定。
- 需要明确哪些页面未来可由 RN/Flutter/Hybrid 承载，哪些页面保留原生。

## 推荐页面流

```text
首页/目录页
  ├─ 手册详情页
  ├─ 搜索页
  ├─ 车辆状态页
  ├─ 原生能力页
  └─ 设置页
```

在横屏布局中，手册目录和详情可以同时出现在同一个页面。搜索结果点击后，可以直接更新右侧详情区域，也可以进入详情页。

## 路由草图

原生基准可以先使用简单路由模型，后续再接入 Navigation Compose。

```kotlin
sealed interface AppRoute {
    data object Manual : AppRoute
    data object Search : AppRoute
    data object Vehicle : AppRoute
    data object NativeCapability : AppRoute
    data object Settings : AppRoute
    data class ArticleDetail(val articleId: String) : AppRoute
}
```

如果使用 Navigation Compose，可以让路由字符串和业务参数保持清晰：

```text
manual
search
vehicle
native-capability
settings
article/{articleId}
```

课程中更关注导航边界，而不是某个导航库的全部 API。学习者需要知道哪些页面由 Android 壳控制，哪些页面未来可能交给 WebView、RN 或 Flutter。

## 布局策略

| 屏幕宽度 | 推荐导航方式 | 说明 |
| --- | --- | --- |
| 小于 600dp | 单列页面 + 顶部/底部入口 | 适合手机预览或移动 Web 对照 |
| 600dp 到 960dp | 主从布局，目录窄列 | 适合平板或中控模拟器 |
| 大于 960dp | 稳定左右分栏 + 顶部功能入口 | 适合智能座舱横屏主场景 |

导航实验不要只验证一种屏幕尺寸。至少在一个手机宽度和一个横屏宽度下观察界面是否还能正常切换。

## 动手路径

1. 定义应用顶层路由和导航状态。
2. 在首页放置手册、搜索、车辆状态、原生能力、设置入口。
3. 手册目录点击后，更新当前选中文章。
4. 搜索结果点击后，复用同一个详情展示逻辑。
5. 记录哪些页面未来适合跨平台承载，哪些页面更适合作为 Android 壳页面。

## 实验任务

1. 建立应用顶层页面结构。
2. 实现首页、搜索、车辆状态、原生能力、设置的导航入口。
3. 在手册目录和详情之间建立选中关系。
4. 记录当前导航设计，说明后续混合接入时哪些页面适合作为原生壳页面。

## 阶段挑战

- 搜索结果点击后，不新建一套详情 UI，而是复用手册详情组件。
- 横屏下点击目录只更新右侧详情，小屏下点击目录进入详情页。
- 在原生能力页中放置文件、相机、通知三个入口，即使当前只实现其中一个。

## 完成后复盘

- 首页无需额外跳转即可看到核心内容入口。
- 横屏下目录与详情布局稳定。
- 小屏下页面可以正常切换。
- 页面跳转不会导致核心状态全部丢失。

## 对照思考

- 原生导航和 React Navigation、Flutter Navigator 的差异是什么。
- 混合接入时，应该由原生壳统一导航，还是由跨平台页面内部导航。
- 页面状态恢复和 Android 生命周期之间有什么关系。
