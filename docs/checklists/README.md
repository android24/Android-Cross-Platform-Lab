本目录用于承接课程建设过程中的审验工作。

课程正文负责讲清楚“学什么、为什么、怎么做、如何和其他技术栈对照”。审验清单负责在每次完成章节后检查内容是否按课程路线执行。两者分开维护，避免正文被大量验收条目打断。

## 审验原则

- 先审结构，再审内容。
- 先检查是否符合课程路线，再检查单节文字是否完整。
- 验收口径不作为正文主线，只作为章节完成后的复盘工具。
- 每一章都要能回答它属于哪一篇、服务哪个工程目录、和贯穿项目有什么关系。
- 如果章节内容偏离课程规划，优先调整结构，而不是继续补散点内容。

## 使用方式

每次完成一个章节或一次较大内容调整后，按对应清单做复盘：

```text
1. 对照清单逐项检查。
2. 标记通过、需调整或暂缓。
3. 对需调整项回到正文修改。
4. 本地构建通过后再决定是否提交和推送。
```

审验清单不是给学习者背诵的内容，而是课程作者维护课程一致性的工具。
